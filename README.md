# fmeyer.ucsd.edu redirect

fmeyer.ucsd.edu now redirects to the Situational Awareness Laboratory website at https://sa-lab.ucsd.edu
(served from the meyer-ucsd.github.io repo).

`index.html` handles the home page, and `404.html` handles every other path, so
fmeyer.ucsd.edu/<file> goes to sa-lab.ucsd.edu/<file>.
